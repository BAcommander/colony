## How to use the pack

Start with 11, then carry only the tested improvements into 12–14. Use the Music prompt/description field, instrumental output and the actual supported duration/model. Check displayed generation cost; the assistant has not generated anything or spent credits. The long prompt specifies eight minutes; if the UI offers a different duration, change the text and record the actual setting rather than claiming eight minutes were made.

The first-scene `v2-control-120s.txt` changes only the old pilot's stated duration from 60 to 120 seconds. This is a preserved-wording control, not a new V2 master. Compare two independent controls with two V3 outputs if affordable; alternatively start with the two V3 variants and record that no old/new comparison was performed. No matched UI seed is assumed.

Choose the musical bed before adding ambience. Use SFX prompts in a separate sound-effects workflow, with clear source detail and no music. The proposed sources are artistic interpretations of these scenes, not field recordings made on alien planets. Do not put exterior wind at the listener's indoor position or assume every enclosed room needs audible weather. Test each source's level and recurrence separately. Prior Rainline/shoreless gain values belong to their exact sources and are not universal presets.

Keep a dry export, a candidate ambience mix and exact settings. Match audition loudness with gain; −23 LUFS is a useful continuation of our comparison setup, not a mandated publication master level. Do not add compression just to hit a reference statistic. Evaluate SFX plateau peaks and quieter music, joins and full-session comfort. Preserve the once-only opening from the current production workflow during final assembly; the music source should remain free of a baked production intro.
